# Computer Networks Practicals

This repository contains my Computer Networks practical work completed using Cisco Packet Tracer.

## Practicals

### 1. Configuring RIPv2 (Classless) Routing in Packet Tracer
This practical demonstrates the configuration and verification of RIPv2 classless routing between different networks.

**Files:**
- `lab.md` – Practical documentation and commands
- `images/` – Screenshots of the configuration and results

### 2. Configuring BGP Routing in Packet Tracer
This practical demonstrates the configuration and verification of BGP routing between different autonomous systems.

**Files:**
- `lab.md` – Practical documentation and commands
- `images/` – Screenshots of the configuration and results
